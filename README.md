# gbcamera

[![GitHub Pages](https://img.shields.io/badge/demo-online-green)](https://mad4j.github.io/gbcamera/)

**gbcamera** is a GameBoy Camera simulator created by [mad4j](https://github.com/mad4j). This project aims to replicate the nostalgic experience of the original GameBoy Camera, right in your browser.

## Features

- Simulates the classic GameBoy Camera interface and functionality
- Capture and view images in a retro pixel-art style
- Web-based: No installation required, runs in any modern browser
- Free and open source (GPLv3)

## Demo

Try it out online: [https://mad4j.github.io/gbcamera/](https://mad4j.github.io/gbcamera/)

## Getting Started

### Prerequisites

- Modern web browser (Chrome, Firefox, Edge, Safari)

### Usage

1. Visit the [online demo](https://mad4j.github.io/gbcamera/).
2. Use your webcam to capture images in GameBoy Camera style.
3. Save or share your creations!

### Local Development

To run the project locally:

1. Clone this repository:
    ```bash
    git clone https://github.com/mad4j/gbcamera.git
    cd gbcamera
    ```
2. Open `index.html` in your browser (no local webserver needed).
